# ailoom-cli

[AILoom](https://github.com/QuincySx/AILoom) 的命令行工具：在项目之间管理 AI 编程工具（Claude Code、Codex 等）的 Skill、规则与 Agent。

```bash
npm install -g ailoom-cli
ailoom web        # 启动本地网页并打开
```

首次运行会从 GitHub Release 下载当前平台的二进制并校验 sha256。支持的平台、内网镜像与离线安装见 [PLATFORMS.md](PLATFORMS.md)；完整说明见 [安装文档](https://github.com/QuincySx/AILoom/blob/main/docs/guide/INSTALL.md)。
