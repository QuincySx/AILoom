# 仓库身份与配置作用域分离，个人调整放在本地层

用户需要同仓 worktree 共享默认配置，同时对子项目单独调整，并保持公司已跟踪指令文件不变。新增模型将 Git 仓库归组、实际工作树、子项目作用域和业务 Project 分开；个人配置/文档源数据放在仓外，宿主必须的本地入口由适配器受控生成，默认不使用 skip-worktree/assume-unchanged 隐藏公司文件修改。

这是本轮实现建议，待 AIL-039/040 完成兼容契约并验收后生效；不追认现有 v1 已支持继承。取舍是增加本地注册和宿主适配复杂度，换取工作树独立、个人改动不混入公司文件、对子项目可解释的覆盖。相同远端仅提供不同克隆的关联候选，不自动认定为同一个业务 Project。完整约束见 [计划](../initiatives/local-console.md)。
