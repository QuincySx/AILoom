# CC Switch 来源迁移验收

## 已验证

- 8 项迁移专项测试：官方来源字段、嵌套路径与含斜杠分支、HTTPS/SSH/skills.sh 解析、危险地址与路径拒绝、离线扫描、真实隔离 Git 仓库的拉取/登记/重复导入/更新溯源、歧义匹配拒绝、分支冲突和过期预览拒绝。
- 专项测试还通过模拟 CC Switch SQLite 数据库验证：只提取 skills 来源字段，不带出其他表的合成标记，读取前后数据库内容一致，数据库符号链接被拒绝。
- 14 项控制台接口测试通过，包括迁移会话鉴权、显式读取确认、自定义目录授权、未知来源拒绝、伪造预览路径拒绝。
- 8 项合集回归、4 项前端组件测试通过；构建、格式与 diff 检查通过。
- Chrome 实际 UI 点击扫描模拟数据库通过：2 条来源记录、1 条可选、1 条缺失来源禁选；JSON 备用入口的错误提示、全选/取消、HTML 转义、Esc 与焦点恢复、390px 窄屏布局通过，无 JS 异常。
- 已核对生产模块不包含 Quincy、<user>、/Users 或 /Volumes 用户绝对路径。默认路径由服务运行时 HOME（macOS/Linux）或 USERPROFILE（Windows）计算，自定义目录由用户选择。

浏览器测试使用 `/private/tmp/ailoom-cc-migration.zpwffx/synthetic-source` 内现场创建的模拟数据库，截图位于同目录父级的 `direct-cc-switch-*.png`。这些路径没有写入生产模块默认值。

## 未验证与边界

- 没有读取用户真实 CC Switch 数据库、没有替用户执行真实来源迁移。用户可在产品中主动点击扫描、预览和登记。
- 没有对真实私有仓库执行 SSH/认证拉取；协议解析已测，实际拉取复用合集 Git 实现。
- 未验证非 macOS SQLite CLI 兼容性、旧版 CC Switch schema、完整屏幕阅读器。
- 当前同一合集只能锁定一个分支；同仓库多分支报冲突，不静默选择。

## 两种管理方式与紧凑列表追加验收

- 默认 AILoom 托管；可切换 CC Switch 外部管理，选择实际 Skill 存放目录。后端要求目录授权，预览和确认绑定管理方式与路径。
- 10 项合集测试、24 项同步计划/应用测试、14 项控制台接口测试通过；4 项前端组件测试通过。
- 新增端到端测试验证：外部管理不产生 Git 缓存或 SkillStore 副本，项目直接链接原目录；外部修改立即可见且不会变成托管内容冲突；路径失效报错，坏链可停用，解除引用不删除移走后的原文件；Git 更新入口拒绝外部来源，预览后内容变更和符号链接越界被拒绝。
- Chrome 用模拟数据库完成管理方式切换、外部预览和登记；重复预览显示已存在；资源卡不提供 Git 更新按钮。
- 60 条来源的真实 UI 扫描：折叠行高不超过 72px，列表可视高度不超过 320px，名称/仓库搜索有效；Esc/焦点恢复和 390px 窄屏检查通过，无 JS 异常。
- 截图：`/private/tmp/ailoom-management-review.aVRCfm/final-cc-compact-60.png`、`final-cc-switch-mobile.png`、`final-cc-external-preview.png`。
- 所有扫描/部署测试仍只使用隔离测试数据，不读取用户真实 CC Switch 数据库，不替用户登记真实来源。外部目录实时跟随内容，不提供历史版本回滚；切换已登记来源的管理方式须先停用旧引用再重新登记。
