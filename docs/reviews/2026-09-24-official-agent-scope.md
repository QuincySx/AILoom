# 官方 Agent / Subagent 适配范围

用户确认：当前只做各工具官方 Agent / Subagent 配置适配。Pi 固定适配官方 subagent 示例，不扩展到第三方实现。

## 当前交付边界

- AILoom 管理能力来源、配置选择、格式转换、文件部署和撤销。
- Pi 的代理配置生成到 `.pi/agents/*.md`，由已安装的官方 subagent 示例读取。调用使用 `agentScope: project` 或 `both`。
- 生成配置不等于扩展已安装或已加载。能力 API 显式返回扩展前提；资源行显示“已配置”和“依赖官方扩展”，详情说明加载未验证。应用结果只确认文件写入。
- 不自动安装扩展，不改全局 Pi 配置，不跳过官方示例的信任确认。
- Pi MCP 仍需独立适配的扩展，不因支持 subagent 就视为支持 MCP。

## 后续统一插件管理

插件发现、安装、版本锁定、更新、兼容性检查、加载验证和卸载将作为独立功能统一设计，覆盖所有 AI 工具。第三方插件与第三方子代理实现届时按需接入。本阶段不增加这些入口或维护逻辑。
