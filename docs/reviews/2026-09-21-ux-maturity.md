## 第 2 轮：作用域层级可视化 + 工作树子目录微调（用户点名需求）——已完成 ✅

用户反馈：「工作树的子文件我如果有继承后单独微调的需求该怎么搞」「UI 完全看不懂」。
查证结论：**后端与 API 一直支持四档作用域**（`/api/profile/select` 的 worktree×subproject 组合 → profile trace 的
repo_default / repo_subproject / worktree_override / worktree_subproject 五层键），但项目页只暴露了两档，
子目录微调只能绕道旧 scopes 页 —— 这就是「想微调没入口、UI 看不懂」的根源。

改动（pages/projects.js）：

1. 「保存范围」下拉扩为**四档**：项目默认 / 项目默认·指定子目录 / 仅当前工作树 / 仅当前工作树·指定子目录；选子目录档出现「子目录（相对当前工作树，须已存在）」输入。
2. 新增**层级说明行**（常驻）：随选择实时解释当前配置的是哪一层、谁会继承它（例：「正在配置【当前工作树 · 子目录 web】：只影响这个子目录；没设置的依次沿用工作树、项目默认。」）。
3. 所有保存点（宿主行、引用行、添加 Dialog、移除 Dialog）与 plan 预览、effective 读取全部携带当前 scope；保存反馈与确认窗标明所在层（例：「已保存 1 条引用（当前工作树 · 子目录 web）」）。
4. effective 读取按当前子目录 scope 调用（修复：切到子目录层后本层引用不可见的缺陷）。
5. 文件夹项目（非 Git）不变：只有项目默认一层，说明行同样常驻。

验收（`iter2-scope.mjs` 13 项全绿，真实 UI+API+磁盘，Git 项目丙+子目录 web）：
四档下拉与说明行 → 子目录层添加 retrieval-tips（反馈标明层级）→ API 双读（父级不受影响 / `scope=web` 启用）→
预览并应用后**文件只落在 `web/.claude/skills/`，项目根零文件** → 移除确认窗标明所在层 → 移除后子目录恢复继承 → 甲隔离不受影响。
回归：全套门禁重跑全绿（110 / relink / 111 / 113 / 114 / 115 / 112 / 118 / 119；ail114 两处断言随新文案同步）。
截图：ux-iter/iter2-01~04。
遗留发现：`/api/effective` 的子目录参数名是 `scope`（不是 `subproject`），两套 API 参数名不一致，记入待清理。

## 第 3 轮：工作树 = 生效视图 + 增删差异（用户纠正方向后重构）——已完成 ✅

用户纠正：「Git worktree 本身就是同一个项目……理论上应该有个默认继承……在根目录那份配置里稍微删点或加点东西。」
即：**不要让用户选「写入哪一层」，而是打开工作树直接看到生效配置，加/减自动成为差异**。第 2 轮的四档下拉
仍是存储层思维，推翻重做：

1. 「配置哪一层」改为**「正在编辑」视角条**：项目默认（所有工作树的基底）/ 当前工作树（默认继承项目）/ 当前工作树 · 指定子目录。项目默认子目录模板（repo_subproject）降为 scopes 高级页功能，不再占主界面。
2. **工作树视角 = 生效视图 + 差异动作**（宿主/Skill/MCP/Agent/其他资源全部页签）：
   - 跟随默认的启用项 → 徽章「已启用」+ 次要「跟随项目默认」+ 动作**「在此工作树移除…」**（写本层停用，确认窗明示「项目默认仍然启用，其他工作树不受影响」）
   - 本层移除的项 → 徽章「已在此移除」+「项目默认仍启用」+ 动作**「恢复跟随默认」**
   - 本层添加的项 → 「已启用」+「在此工作树添加（项目默认未启用）」+ 恢复跟随默认
   - 默认停用项 → 「已停用 · 跟随项目默认」+「在此工作树启用」
   - 不再出现 select「启用/停用/恢复继承」三态控件与「本层设置」措辞（项目默认视角保留）
3. 层级说明行改按视角解释：「它默认全部继承项目默认；你在这里做的只是增删差异。」删除切换时的冗余 toast。
4. 语义明确化：「在此工作树移除」=本层显式停用 → 预览并应用后清理本工作树的文件；「恢复跟随默认」=回到继承。

验收：ail114 Part 7 改为新语义端到端（跟随默认 → 在此工作树移除 → 应用后本工作树文件被清理且项目默认不动 → 恢复跟随默认 → 应用后文件恢复）；iter2-scope.mjs 13 项（子目录视角差异）全绿；全套门禁（110/relink/111/113/114/115/112/118/119）重跑全绿。截图 ux-iter/iter3-01~02。
脚本可重复性加固：ail114 开头清理段补工作树层 inherit 与丙磁盘兜底清理；reset115.sh 增加 web/.claude 清理；两处断言随新交互同步。
