# 目录工作区重做

用户确认的操作方式：文件管理器——左侧目录，右侧能力列表，底部统一应用改动。

## 已实现

- “我的目录”直接进入工作区，记住上次选择的目录与工作副本。
- 左侧展示登记项目及实际子目录；右侧只展示所选目录的工具、能力和状态。
- 添加、移除和恢复选择先保存配置，底部“查看改动”统一预览并应用。
- 预览显示能力名、工具、文件路径；成功后可进入操作记录撤销。
- 项目默认设置、说明和本地文件管理收进次级入口。能力库的本地文件编辑默认折叠。
- 桌面双栏布局，窄窗口改为上方目录、下方内容，应用栏保持可见。

## 走查中修复

1. 部署状态以前只看历史清单，文件撤销后仍可能显示“已应用”。现在读取实际目标条目的哈希；覆盖所有生成能力类型。
2. 没有显式覆盖配置的子目录也可以应用继承能力。原有根目录计划可能清理这些子目录入口。现在按适配器目标路径确定归属，父目录不清理子目录；嵌套子目录同样隔离。
