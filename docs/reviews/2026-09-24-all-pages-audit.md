# 全页面与弹窗文案检查

检查范围：全部 12 个页面模块、13 个业务组件，以及路由入口。不是仅检查当前截图。

## 页面清单

| 模块 | 处理 |
| --- | --- |
| workspace | 检查目录、能力选择、详情、应用确认与结果；保留改动和冲突提醒 |
| library | 检查导入、使用项目、本地编辑；单一能力列表与顶部更新入口 |
| projects | 精简添加项目、旧配置页、工具检测、本地文件删除提示；保留删除对象与恢复方式 |
| projectSettings | 只保留项目说明和名称分类，无重复能力配置入口 |
| instructions | 无项目时提示先选择项目，不再暴露 root 错误 |
| tasks | 保留操作、结果、撤销后果，技术编号收进详情 |
| onboarding | 精简三步说明，添加项目直接到管理页，删除重复入口说明 |
| sources | 精简更新与项目状态说明；能力仅列一次，版本记录折叠 |
| workflows | 简化文档流程说明、名称选择，不展示流程内部 ID |
| scopes | 旧链接转到目录页；旧组件文案也已清理 |
| overview | 旧链接转到目录页；旧说明与失效术语清理 |
| samples | 已检查，属于开发组件样例，保留技术标签，不作为用户导航入口 |

## 业务组件清单

| 模块 | 处理 |
| --- | --- |
| directoryPicker | 简化目录提示与已添加标记 |
| resourcePicker | 去掉重复使用说明与内部资源路径 |
| scopePicker | 项目名替换仓库 ID，删除 Worktree ID 列 |
| resourceReferences | 只读使用位置和跳转，包含沿用上级的目录 |
| collectionsPanel | 检查更新、移除与异常提示；重复列表不在能力库渲染 |
| workflowStageList | 阶段中文名、能力名称、输入选择；删除版本校验机制解释；补齐 notify 导入 |
| resourceRow | 精简移除、停用、沿用上级确认，保留实际后果 |
| ccSwitchImport | 只保留迁移差异、目录与必要操作；本地修改丢失提醒保留 |
| planPreview | 删除内部项目/Worktree ID，简化应用、结果、撤销与验证说明 |
| importDialog | 保留来源输入、预览、导入结果 |
| importPreview | 精简导入、检查更新与冲突提示，版本信息仍可查 |
| instructionsPanel | 项目说明编辑，团队内容按需展开 |
| capabilityMatrix | 简化工具、选择、当前状态标签，去掉配置层解释 |

组件表按模块列出；`importPreview` 同时包含导入预览与更新面板。

## 验证

- 25 个页面/业务模块均通过 JavaScript 语法检查。
- 前端组件 6 项测试、Rust 构建、diff 空白检查通过。
- Orca 内置浏览器逐一打开管理目录、首次使用、旧更新页、流程页、操作记录、独立说明、项目资料、项目说明、旧 scopes/overview 链接、开发样例、能力库。
- 空流程页已检查；未创建或导出真实文档，写入结果分支通过代码审阅检查，未声称逐个执行所有破坏性操作。
- 发现独立说明页缺少项目上下文的错误并修复。旧链接跳转保留，新版最终停留在能力库。
