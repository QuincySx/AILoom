## 目标与视图规则（AIL-121 契约）

- 目录视图（viewKind=directory）：Git 根目录→worktree_override；Git 子目录→worktree_subproject(rel)；非 Git 根→repo_default；非 Git 子目录→worktree_subproject(rel)。
- 项目共享视图（viewKind=project-shared）：repo_default。编辑器范围文案固定「整个项目」。
- 任何项目/工作目录/目录/视图切换递增 generation：旧读取丢弃、旧计划失效（服务端指纹双保险）。
- 写请求在发起时冻结目标（root+scope+worktree 标志），响应按 generation 决定是否采纳。

## 已收口的旧入口

- 项目页不再出现「正在编辑哪一层」下拉与手填子路径主入口；目录选择 Dialog 取代（AIL-122）。
- 项目页「高级配置…」→ `#/scopes` 携带项目上下文；scopes 消费后写回一次性恢复记录，「返回」不丢目录。
- scopes 深链（旧书签）仍可用：无上下文时只读浏览，写入按钮要求本页显式选择目标。
- 全局 `#/instructions` 个人指令页保留为遗留；项目 Markdown 指令的正式入口在项目共享设置（AIL-124）。
