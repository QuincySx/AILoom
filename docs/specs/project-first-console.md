# 项目优先的控制台结构

## 页面与数据归属

- 默认首页为项目列表：搜索名称、路径、远端，按自定义分类与 Git/文件夹类型筛选。
- 右上角新建项目：选择真实本机目录（macOS 原生对话框，其他平台手动路径），Git 优先识别，登记名称与分类。
- 项目详情：工作目录选择、宿主、Skill、MCP、Agent、个人 Markdown 指令、预览与应用。
- 全局资源中心：导入来源、查看资源、检查更新、确认更新与安全移除。项目页不重复下载资源。
- 任务与流程保留为辅助入口；旧引导与作用域页面保留兼容路由，不作为默认导航。

## 存储与安全边界

项目复用现有 repos/<repo_id>/registry.json，展示元数据保存在同目录 project.json；不创建另一套仓库身份。Git 同一仓库工作树共用项目默认配置，不同 clone 不按远端地址合并。普通文件夹使用既有 nongit 身份。

所有项目指令 API 必须传入已授权 root，不回退到服务 cwd；非 Git 项目同样支持。Markdown 保存到本机数据区，部署仍须预览与应用。项目添加只登记，不修改项目代码。

当前控制台是本机 HTTP 页面，不是原生 WebView 容器。macOS 目录选择通过本机服务调用固定 AppleScript，不用浏览器文件上传伪装绝对路径。取消不登记项目。

## 验收

空数据默认项目页；新增项目、搜索、分类、重启后列表与分类保留；A/B 项目指令隔离；缺失 root、未授权 root 拒绝；项目显式选宿主与资源后才能预览应用；桌面与窄屏无横向溢出。
