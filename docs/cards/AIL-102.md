## 按顺序实施

1. 核对一来源多资源分组；真实 Git URL 与分支用于同步，CC Switch/skills.sh 仅作为导入渠道。
2. 导入 Dialog 覆盖 GitHub/GitLab/SSH/本地/目录入口，预览后确认；管理方式明确为 AILoom 托管或外部维护。
3. 管理项目引用打开 Dialog，限定当前来源或 Skill，展示已有引用位置，新增/停用后双向页面一致；不跳进通用作用域页。
4. 检查更新、可更新、失败、无更新、版本过期分别回显；更新资源库不自动应用所有项目。
5. 删除来源必须列出使用项目，引用存在时阻止或明确先解除；不删除外部原文件。路径/历史记录放次级详情。
