## 背景

E5004 被大量用作通用冲突码；E2006/E2007 未登记；IO 错误落到 E9000 且无路径；同目录重复导入报 E2006 冲突。

## 顺序步骤

1. 梳理 `USER_CONTENT_CONFLICT` 的全部使用点，按契约码段归位（个人库、合集、工作流、profile 等）。
2. `From<io::Error>` 带上路径；可预期的输入错误先校验并给出对应码段。
3. 个人库重复导入按导入摘要比较，内容相同返回 noop。
4. 测试断言 `error::code` 中每个常量都出现在 CONTRACTS §5 码表中。

## 必须验收

- [x] 码表测试通过；CONTRACTS 变更记录同步。
- [x] 重复导入同一目录返回 noop。
