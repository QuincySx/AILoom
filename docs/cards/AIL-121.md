## 按顺序实现

1. 先补复现测试：项目默认停用、当前工作树启用、web 无覆盖；web 必须显示启用且来源为工作树，不得根据项目默认推断。
2. 定义唯一只读目标快照（建议字段 projectId、worktreeId、rootPath、relativeDir、resolvedPath、viewKind、generation）；目录视图与项目共享设置使用不同 viewKind。字段为建议契约，不是假定已有 API。
3. 集中适配已有 effective/select/scanProjectSkills/deployStatus/plan 接口，逐项记录 root、scope、sub 的真实意义。不要简单把所有 root 拼上子路径；扫描范围、配置范围、部署清单分别验证。
4. 有效状态与来源以 resolver 的完整结果为准；diffOf 不能只取 repo_default 与当前层。恢复继承必须计算移除当前覆盖后的真实上游结果，包含工作树和已有子项目模板层。
5. 项目/工作树/目录/视图切换均递增 generation；丢弃旧读取结果，计划失效，未保存草稿先确认。写请求冻结目标，响应不得冒充新目标的成功。
6. 非 Git 根目录维持现有身份；核实子目录持久化/解析/计划能力，有缺口在本卡补最小契约及回归，不创建虚假 Git 身份，不将子目录静默保存到根。
