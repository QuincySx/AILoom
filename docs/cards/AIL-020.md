# AIL-020 · 经验总结提示与会话摘要

- 状态：Backlog
- 里程碑：M3
- 相对规模：M（复杂度提示，不是工时承诺）
- 依赖：AIL-015, AIL-017, AIL-019
- 负责人：待领取

## 目标与交付

按干预/工具失败提示总结；每会话最多一次；月度会话摘要本地保存；共享作为显式独立操作。

## 验收标准

- [ ] 日常长会话不单凭调用量触发
- [ ] 重复 Stop 不重复提示
- [ ] 关闭提示仍可统计
- [ ] 共享默认仅计数和工具名
- [ ] 正文脱敏不是无条件上传依据。

## 实施边界

- 本卡限定以上交付；新增范围先更新卡片及依赖。
- 参考实现用于理解机制，AILoom 的格式与行为以 AIL-001 契约为准。
- 宿主工具路径、格式和 Hook 能力须在实施时按官方文档与真实版本核实。
- 完成后记录验证命令、结果、支持版本及未覆盖项，再改为 Done。

## 文件职责（建议布局）

src/events/friction.rs、src/session_summary.rs、tests/friction.rs。已有等价模块时复用，不为匹配路径复制逻辑；共享类型只有一个定义。

## 输入与输出

输入：SessionMetrics和事件；输出：最多一次提示+本地结构化摘要/Markdown。

## 实施步骤

1. 独立配置分数与阈值。
2. 工具调用量本身不触发。
3. 提示状态按session持久化。
4. 总结提示和上传开关分离。
5. 本地摘要限制自由文本。
6. 共享模式重建计数版而非复制本地文件。
7. 复用贡献审核路径。

## 必测场景

- [ ] 500次无错误调用不触发。
- [ ] 打断达到阈值触发一次。
- [ ] 进程重启重复Stop不重复提示。
- [ ] 关闭提示仍统计。
- [ ] 默认共享中无prompt。
- [ ] 手动总结在无事件时能明确说明不足。

## 明确不做

- 不在Stop自动开LLM总结请求。
- 不把脱敏当保证无秘密。
- 不自动上传本地摘要。
