## 目标与交付

定义 session-start/prompt/tool/stop 的标准事件、工作区标识和去重键；适配至少一个宿主，另一宿主提供明确支持矩阵。

## 验收标准

- [ ] 事件不串项目
- [ ] 超时或 CLI 失败不阻塞宿主工作
- [ ] 注册卸载幂等
- [ ] 后台更新不声称本轮已加载新资源
- [ ] 重复事件可去重。

## 输入与输出

输入：宿主Hook stdin payload；输出：标准事件并追加到workspace事件文件。

## 实施步骤

1. 定义schema_version/event_id/session_id/workspace_id/tool/time/type。
2. 每宿主解析器独立。
3. 只读取必要字段。
4. 持久化后立即结束。
5. 并发append和去重有策略。
6. foreground限时，昂贵操作后台。
7. 注册走托管清单。

## 必测场景

- [ ] 重复payload重复送达聚合幂等。
- [ ] 未知字段向前兼容。
- [ ] 坏JSON诊断但不使宿主中断。
- [ ] 后台没有继承错误cwd。
- [ ] 两个同时会话session id不撞。
- [ ] 事件中不默认保存完整prompt。

## 明确不做

- 不轮询所有用户历史文件。
- 不让Hook失败阻塞写代码。
- 不把Stop解释为进程退出。
