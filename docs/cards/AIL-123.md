## 按顺序实现

1. 封装共享 ResourceRow：名称/说明为主，生效来源、当前目录设置、逐宿主部署状态可区分；Skill/MCP/Agent 复用结构，但保留能力与参数差异。
2. 添加使用已有 resourcePicker Dialog：搜索、已选、已启用/已停用提示；显式停用的资源允许重新添加。+导入进入同一 Dialog 的下一步，返回保留搜索和选择，不堆叠失控弹窗。
3. 导入成功进入全局中心并回选资源；取消项目添加不回滚已完成的全局导入，必须明确告知。部分成功逐项报告，重试仅处理失败项。
4. 继承启用用“在此停用”；本地覆盖用“恢复继承”；无上游启用的本地新增可“移除”。确认窗展示实际目标和预测结果，不把清除覆盖等同于停用。
5. 本地未托管 Skill 独立区域，显示扫描目录及真实路径，只有查看/帮助/双重确认删除，不伪装成资源中心可更新条目；复用 AIL-112 的安全删除。
6. MCP 缺凭据和宿主不支持时明确阻止误报可用；凭据存储仍由 AIL-116 负责，不在此重复实现。
