## 目标与边界

让用户选真实目录，而不是学习 repo/worktree/wt-sub。

先读[执行总纲](../archive/initiatives/directory-ux-2026-09-21.md)。保留现有未提交改动；本卡是后续实现规划，不是已实现声明。复用现有 vanilla JS/CSS、Dialog、服务接口，不重写框架。

## 按顺序实现

1. 复用现有 Dialog、表单、Combobox；目录选择器先以静态夹具覆盖根目录、嵌套目录、空结果、失联，保证统一控件高度和键盘操作。
2. Git 多工作树才显示工作目录选择；单工作树可展示静态名称。非 Git 使用同一目录导航，只隐藏 Git 特有信息。
3. 使用受限 fsList 按需展开目录，不递归扫描整个磁盘；搜索明确限定已加载目录，或实现有界服务端目录搜索并展示范围。
4. 标注有单独配置的目录；标记来自真实配置记录，不根据文件夹存在猜测。已登记但失联的配置目录可查看、不可应用。
5. 选择只更新浏览目标，不自动注册子项目、不写配置；首次资源增删才创建相应覆盖。目录被删除、越界、符号链接逃逸由服务端再次校验。
6. 移除日常页的配置层下拉与手填子路径主入口；高级路径输入可放 Dialog 内，提交同样校验。保留已有高级模板数据，不做破坏迁移。
