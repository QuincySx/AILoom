# AIL-006 · 资源清单与项目角色解析器

- 状态：Backlog
- 里程碑：M1
- 相对规模：L（复杂度提示，不是工时承诺）
- 依赖：AIL-001, AIL-004, AIL-005
- 负责人：待领取

## 目标与交付

解析 Skills、Rules、Docs、Agents、MCP 的统一资源清单；计算公共、角色、项目选择集合；明确来源和稳定资源身份。

## 验收标准

- [ ] 角色∪项目规则有测试
- [ ] 未激活项目不会拿全部资源
- [ ] 同名冲突显式报错
- [ ] 路径穿越拒绝
- [ ] 每个选中/排除资源可解释原因。

## 实施边界

- 本卡限定以上交付；新增范围先更新卡片及依赖。
- 参考实现用于理解机制，AILoom 的格式与行为以 AIL-001 契约为准。
- 宿主工具路径、格式和 Hook 能力须在实施时按官方文档与真实版本核实。
- 完成后记录验证命令、结果、支持版本及未覆盖项，再改为 Done。

## 文件职责（建议布局）

src/resource.rs、src/manifest.rs、src/resolver.rs、tests/resolver.rs。已有等价模块时复用，不为匹配路径复制逻辑；共享类型只有一个定义。

## 输入与输出

输入：SourceSnapshot+WorkspaceBinding；输出：DesiredResourceSet与逐资源selected/excluded reason。

## 实施步骤

1. 先schema校验再枚举资源。
2. 按稳定ID排序。
3. common显式共享。
4. 角色与项目取并集。
5. learnings只由project/shared筛选。
6. 工具target筛选独立进行。
7. namespace中引用丢失或目标名冲突报错。
8. 对Agent/MCP执行同一AILoom选择契约。

## 必测场景

- [ ] 两个source同名但目标冲突不能最后写入者胜。
- [ ] 角色不应扩大项目经验范围。
- [ ] 未知namespace失败。
- [ ] 空项目保持shared。
- [ ] symlink逃逸和../资源路径拒绝。
- [ ] tags未来加入不改变身份语义。

## 明确不做

- 不读取所有项目经验后再让LLM自行过滤。
- 不把角色当项目父级。
- 不对同名资源隐式覆盖。
