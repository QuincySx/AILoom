## 按顺序实现

1. 日常目录页与项目共享设置显式分开；共享设置用独立项目内路由，返回保持原目录、页签、搜索条件。项目名称/分类这种短表单继续使用 Dialog。
2. 将现有项目默认编辑放入共享资源页；进入前保护草稿，页头不再显示“只影响 web”。项目共享页不显示一个禁用却仍暗示 web 的目录选择器。
3. Markdown 指令入口归项目共享设置；若保留目录页入口，只展示范围说明和前往项目指令链接，不在目录标题下直接保存全项目。
4. 保留现有指令保护、冲突及预览；不把布局调整等同于完成 AIL-117 的宿主文件规则更新。展示实际受支持能力，不承诺所有宿主均支持目录指令。
5. 项目默认改变列出受影响工作目录，已有目录覆盖保持；预览不得默默扩大到其他项目。
