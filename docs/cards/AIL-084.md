## 按顺序执行

1. Dialog/Drawer 输入 open/title/content/actions/onClose；打开保存原焦点、限制焦点范围，关闭归还焦点，Escape 遵守未保存提醒。
2. DiffView 展示 before/after、文件路径、操作类型、冲突原因；作为纯展示组件，不执行导出或覆盖。
3. Editor 输入 documentId/content/baseRevision/validation/onChange/onSave，保留光标、滚动与未保存文本，提交期间不以旧响应替换新输入。
4. ConflictPanel 同时保留 local/base/server 内容，提供明确重新加载或合并后重试；不自动采用新 revision 偷过冲突。
5. Markdown 预览默认禁 raw HTML 或严格净化，代码与文件名按文本处理；外部链接限定协议，不执行资源正文。
6. ConfirmAction 必须展示目标、影响范围和动作；普通保存不套重复确认，覆盖/删除等需要具体预览的动作接入相应确认。
