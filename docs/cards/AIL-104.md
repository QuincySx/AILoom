## 按顺序实施

1. MCP 页只展示本项目配置；添加按钮打开可搜索来源选择 Dialog，确认后引用。
2. 配置 Dialog 展示传输类型、启动命令或地址、参数及环境变量引用；区分共享定义与项目覆盖，禁止项目编辑暗改全局。
3. 敏感项不明文回显、不进日志/截图；使用假秘密验收。未支持的配置字段禁止假保存。
4. 移除确认只影响本项目托管配置；预览精确增删改，不覆盖同文件其他服务。连接检测必须用户明确触发，不因打开页面启动进程。
