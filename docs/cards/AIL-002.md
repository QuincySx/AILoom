输入：命令行参数；输出：人类文本或稳定 JSON envelope，错误走 stderr。

## 实施步骤

1. 建立单 crate 的 lib+bin，edition 与 MSRV 写明。
2. 用标准 CLI 解析库，避免手写参数扫描。
3. 实现 help/version 与错误输出。
4. 增加临时目录测试工具。
5. 仅注册实际实现命令，未实现命令不可伪成功。
6. 配置 fmt/clippy/test。
