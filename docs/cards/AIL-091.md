## 按顺序执行

1. WorkflowStageList 显示四阶段及输入版本/产物/需复核状态，阶段动作不自动运行 AI。
2. SkillBindingPicker 从真实资源库选择对应阶段 skill，显示来源和版本；缺项给导入入口。
3. ArtifactList 按稳定 ID 展示对齐/规格/票据/实现/验收材料，支持选中文档与名称编辑，不按标题寻址。
4. ArtifactEditor 复用 Editor 与 ConflictPanel，保存传 baseRevision；重命名后保持当前关联和编辑对象。
5. InputVersionPanel 展示哪个上游变化使哪些产物需复核；人工确认复核须明确动作，不能仅打开页面就清除。
6. ExistingDocumentImport 与 ExportPreview 复用文件授权/差异组件，文档源与导出落点分别显示。

## 必须验收
