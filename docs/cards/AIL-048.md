## 必须交付与验收

- [ ] 关联工作树即使散落不同路径也同组，bare/locked/detached/失联状态可辨；子模块作为独立仓库，不误画成普通子项目。
- [ ] 每项开关显示继承来源及实际宿主能力；修改仓库默认先预览多个工作树影响，默认不写所有发现的工作树。
- [ ] 可添加相对子项目模板、当前工作树特例、移除覆盖恢复继承；不存在目录只提示未匹配，不自动创建业务目录。
- [ ] 切换项目时未保存草稿不丢失、操作目标持续可见；搬迁重关联不会重建丢历史，冲突/不支持状态有下一步。
- [ ] 对照本地控制台规格的共同不变式，提供“验收项→真实入口→操作/命令→结果→证据”映射；未覆盖必需项保持开放。
