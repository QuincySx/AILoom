## 背景

`workspace.css` 在 `:root` 覆盖 `--control-height`，大量硬编码 px 与低于规范的字号；`prompt()` 未走 Dialog；`data-variant` 契约未使用；390px 宽导航竖排折行。

## 顺序步骤

1. 删除全局 token 覆盖，改为 token 化的紧凑密度变体；字号与尺寸改用 token。
2. `workflowStageList.js` 的 `prompt()` 改为 Dialog。
3. 按规范使用 `data-variant`，规范补 `workspace.css` 的定位。
4. 窄屏导航改为横向滚动或菜单。

## 必须验收

- [ ] 浏览器实测 390px / 1280px 截图；按钮高度与字号符合规范。
