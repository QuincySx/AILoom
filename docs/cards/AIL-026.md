## 输入与输出

输入：单个项目源码快照与提取范围；输出：有source span、revision的facts/edges及页面。

## 实施步骤

1. 先选一种语言并写支持矩阵。
2. AST仅抽取可证据化关系。
3. 将解析失败/动态调用记gap。
4. 文件hash做增量基线。
5. 删除/修改先剔旧facts再合并。
6. 可选AI只补描述且与事实字段分离。
7. 产出可重建索引。

## 必测场景

- [ ] 已知fixture依赖/接口位置准确。
- [ ] 更名/删文件无悬空旧边。
- [ ] 增量结果等价全量。
- [ ] 超范围文件计数可见。
- [ ] 跨项目边有明确target而非混库。
- [ ] AI关闭仍能提取结构。

## 明确不做

- 不第一版支持所有语言。
- 不把正则推测标为AST事实。
- 不默认把源码发外部模型。
