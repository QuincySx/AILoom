## 背景

CI 只跑 Rust 稳定版，不验证声明的 MSRV 1.75；前端两套测试与文档检查都不在 CI 中；`tests/ui_browser.mjs` 选择器已过时，各模式失败。

## 顺序步骤

1. 决定 MSRV：在 CI 增加 `cargo +<msrv> check --locked` job；若依赖树已无法在 1.75 编译，则把 `rust-version` 提到实测最低版本并记录理由。
2. CI 增加 `node tests/frontend_components.mjs` 与 `python3 scripts/docs_check.py`。
3. 按当前 DOM 修复 `tests/ui_browser.mjs` 选择器，文件头写清 Chrome 启动方式与各模式参数；能在 CI 跑则接入，不能则在 RELEASE-CHECKLIST 写明人工步骤。

## 必须验收

- [ ] CI 在干净分支上全绿，且故意引入断链 / 状态不一致 / MSRV 违例时分别失败。
- [x] `ui_browser.mjs` 三种模式在本地真实浏览器通过，并留存日志。
