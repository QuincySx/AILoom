## 文件职责

src/hooks/team_spec.rs、src/hooks/render.rs、tests/team_hooks.rs。已有等价模块应复用，共享接口不另起一套。

## 输入与输出

输入：Hook事件、matcher、命令参数、超时及目标工具；输出：原生配置和托管记录。

## 实施步骤

1. 定义执行信任策略并展示待执行内容
2. 仅适配宿主支持事件
3. 命令使用结构化参数或经过明确审查的脚本文件
4. 记录cwd与超时
5. 内置/团队/个人Hook分别归属
6. 更新走plan/apply。

## 验收标准与必测场景

- [ ] 未知事件拒绝
- [ ] 重复注册幂等
- [ ] 超时回收本次子进程
- [ ] 用户Hook保留
- [ ] 无法安全表达参数时报告不支持
- [ ] 新的命令执行能力不能靠普通后台更新默默引入。

## 明确不做

- 不实现任意远程命令控制
- 不让一次Hook失败破坏宿主任务
- 不假定各工具事件一一对应。
