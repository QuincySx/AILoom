## 目标与交付

内置相关性预检查、按需检索、摘要返回的召回 Agent；总结会话并生成贡献草稿的 Skill。

- [ ] 实际任务能拿到相关经验摘要及引用
- [ ] 不相关任务跳过

- [ ] 不自动把全文会话上传
- [ ] 宿主不调用时有手动命令入口。

## 输入与输出

输入：主Agent的任务描述或当前会话；输出：有来源的召回摘要或待审经验草稿。

## 实施步骤

1. 编写简明调用条件。
2. 先用recall check判断覆盖。
3. 限制检索深度/返回条数。
4. 读取命中文档再总结。
5. 结果保留ID和来源。
6. 总结Skill先生成文件再走贡献命令。
7. 默认可关闭并提供手动入口。

## 必测场景

- [ ] 有相关文档时摘要引用正确。
- [ ] 无关任务不继续全库读取。
- [ ] 坏命令不阻塞主任务。
- [ ] 分享文档可审阅。
- [ ] 两个宿主做人工验收记录。
- [ ] 模型不遵守指令时明确是软约束。

## 明确不做

- 不在这张卡发明调度系统。
- 不自动贡献未审摘要。
- 不把主对话全文传给远端服务。
