## 输入与输出

输入：query+允许项目+图/页面快照；输出：有文本和关系证据的排序结果。

## 实施步骤

1. 先过滤允许集合。
2. 文本召回候选。
3. 最多有限hop邻居加权。
4. 对边类型/置信度定义显式权重。
5. 结果输出路径/跨度/关系。
6. 评估集包括依赖、调用、配置及无关查询。
7. 比较纯文本基线。

## 必测场景

- [ ] 图高连接节点不吞掉文本相关性。
- [ ] 两跳扩展可解释。
- [ ] 不存在路径不编造。
- [ ] 过期图提示重建。
- [ ] 对A查询不会因跨项目边召回B禁选页面。
- [ ] 低分返回无覆盖。

- 不默认扩展全图。
- 不让LLM创造边再当真实证据。
