## 目标与交付

支持本地目录与一个远端 Git 源；记录 URL、ref、resolved commit、缓存位置；显式更新锁定版本。

## 验收标准

- [ ] 同一源复用缓存
- [ ] 离线可用已验证版本
- [ ] fetch 失败保留旧快照
- [ ] 默认不执行源仓库代码
- [ ] 日志不输出凭据
- [ ] 业务工作区无缓存副本。

## 输入与输出

输入：SourceSpec(url/path, ref) 与 lock；输出：只读 snapshot路径+resolved revision+content metadata。

## 实施步骤

1. 本地源计算内容摘要并说明可变性。
2. Git操作使用参数数组和受控工作目录。
3. 缓存按规范化源身份隔离。
4. fetch后验证commit并产生不可变快照。
5. 写锁文件前校验完整性。
6. 更新失败继续保留旧锁。
7. 暴露明确refresh入口。

## 必测场景

- [ ] 远端branch移动不改变已锁定版本。
- [ ] 显式更新才产生新revision。
- [ ] 断网读取已有快照。
- [ ] 首次离线无缓存明确失败。
- [ ] 并发fetch串行化。
- [ ] 无效ref不破坏旧缓存。

## 明确不做

- 不要在业务仓库git reset/checkout。
- 不要执行远端hooks或安装脚本。
- 不要默认每次sync追最新main。
