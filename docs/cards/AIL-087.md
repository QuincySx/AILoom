## 按顺序执行

1. 组装侧栏：概览、仓库与作用域、资源库、来源、流程与文档、任务；首次设置作为独立向导入口。
2. 顶部持久显示当前目标、服务连接状态和未保存提示；切换目标走唯一状态 action。
3. 采用明确 hash 路由并定义 URL 参数编码；浏览器前进/后退与刷新恢复当前页面和合法目标，不在 URL 放会话秘密。
4. 页面 mount/destroy 管理事件和任务订阅；离开 dirty 编辑页提供保存/留在此页/明确放弃选择。
5. 首次无配置进入向导，再次进入最近有效目标；目标失联进入选择/恢复页面，不能跳到假成功仪表盘。
6. 概览仅展示已有领域数据和下一步动作，不新增未确认的统计/点赞系统。

- 先核对依赖接口，不用生产 mock、空回调或硬编码成功补齐缺失 API。组件样例可用明确的 fixture，真实页面必须接真实 API。
