## 背景

`console`（前台）、`web`（后台服务）、`dashboard`（7777 端口看板）三个入口并存，文档主入口口径不一。

## 顺序步骤

1. 保留 `web` 为唯一用户入口；`console` 隐藏或标为调试；`dashboard` 并入控制台或在 help 中写明用途。
2. 文档与 help 同步。

## 必须验收

- [x] help 与 QUICKSTART 只推荐一个入口；旧命令有迁移提示。

## 交付记录

负责人：Claude Code（2026-10-02）。决策：用户确认只保留 `ailoom web` 作为用户入口（2026-10-02）。

- **console**：从 help 中隐藏（`#[command(hide = true)]`），运行时提示「这是前台调试入口，日常请用 ailoom web」。命令本身仍可用，供浏览器验收脚本和旧调用方使用。
- **dashboard**：保留，help 改为「Hook 事件实时看板（仅 loopback；独立于网页控制台，日常管理用 ailoom web）」，写明它和网页控制台是两回事。
- **文档**：README、QUICKSTART 只推荐 `ailoom web`；WEB-SERVICE 已说明 `console` 是前台调试入口。

验证：`ailoom --help` 只列出 `web`，`dashboard` 带用途说明；CLI 测试全部通过。
