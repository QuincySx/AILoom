## 按顺序执行

1. RepositoryPicker 用注册 ID 选择仓库，显示名称/位置/失联提示；同远端不同 clone 不自动合并。
2. WorktreePicker 列出当前仓库工作树、分支、位置、detached/locked/prunable/bare 状态；不可部署项禁用并解释。
3. ScopePicker 选择已登记子项目/仓库默认/工作树覆盖，显示继承链和实际相对路径；缺目录显示未匹配。
4. 组件输出 onTargetSelected(TargetContext)，由状态层执行切换，不自行写 profile 或 apply。
5. 重关联入口展示旧身份/候选位置与后端验证结果；非 Git 用同一选择器的路径模式变体。
6. 提供加载/空仓库/歧义/失联/失败/搜索无结果样例，不把列表展示等同已实现选择。
