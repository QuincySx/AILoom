## 按顺序实现

1. 盘点 app.js 全部路由及导航；输出入口/目标/返回地址/写入范围矩阵，包括项目、library、sources、scopes、instructions、tasks、workflows、onboarding、samples。
2. 日常项目不再跳全局 repo-id 表。保留旧 scopes 深链时明确项目上下文；无目标时只允许选择，不靠最近一次全局变量自动写。
3. 源、指令等重复入口复用本轮组件；流程工作台仅保留既有高级定位，不混入项目配置主流程，不实现 Agent Hub。
4. 搜索框、HTML Combobox、Dialog、按钮复用现有 tokens/组件；逐页检查原生 select 是否被正确增强、焦点圈、禁用和错误反馈；不引入新 UI 框架。
5. 正常操作弹窗、页面导航、结果详情各归其位；刷新/后退恢复目标但不意外重放写入，失联目标明确恢复入口。
