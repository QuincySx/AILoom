## 按顺序执行

1. Button 输入 variant/size/disabled/pending/label/onPress；pending 防重复点击，错误由调用方状态呈现，按钮自身不 fetch。
2. Field 包装 label/hint/error/required，Input/Textarea/Select 以 value/onChange 受控，生成稳定 id 和 aria-describedby。
3. 实现 TriStateSelect(value=inherit|enable|disable, inheritedValue, onChange)，三态与最终 effective 分开展示，不能用 checkbox 偷换继承语义。
4. 实现 Checkbox/CheckboxGroup、SearchField；保留原生键盘行为和表单标签，输入过程中不全页重绘丢光标。
5. 各组件具备 update/destroy，不注册 window 业务函数；提供正常、禁用、提交中、错误、长标签示例。
6. 把宿主勾选和资源三态的差异写进使用说明，避免整组只发送 checked=true。
