## 按顺序实施

1. Skill 页默认展示本项目已引用/继承的 Skill，显示真实仓库、说明、状态；不要把全局库存全铺进主列表。
2. 右上角“添加 Skill”打开 Dialog：按来源分组、搜索、勾选、已添加禁选；默认不全选。支持查看说明与路径。
3. 确认后保存明确资源 ID 的项目引用，回到列表并标记待应用；失败保留选择可重试。全局库为空时引导导入并能回到原项目。
4. 每项提供“从本项目移除”确认 Dialog，说明不会删除全局来源或其他项目资源。继承项必须明确停用覆盖与恢复继承的差别。
5. 移除后预览托管入口清理；用户修改/非托管文件显示冲突，不删除原始 Skill；取消无写入。

## 必须走通的真实验收

- [ ] A 添加两个 Skill，B 不变；刷新后引用保留；保存前、保存后、应用后的文件差异分别核实。
- [ ] 继承 Skill 停用后不部署；恢复继承可重新出现；移除不触发 collectionRemove。
- [ ] 大仓库、同名不同来源、来源失效、重复提交、窄屏与键盘操作均可走通。
- [x] 取消不写入；失败可恢复；重复提交不产生重复配置。
- [ ] 保存后刷新与服务重启持久化一致；其他项目和全局源无意外改变。
