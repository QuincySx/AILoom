## 顺序步骤

1. 撤销语义收敛：`jobs.rs` 抽出 `undo_apply` 核心（CLI 持久化任务与控制台活动任务共用）；新增 `undo_persisted`（基于持久化任务）与 `cli_sync`（CLI sync 走 Web 同一应用管道并持久化带撤销清单的 Apply 任务）。
2. CLI 新增 `personal --action undo --id`、`personal --action scan-skills --root [--sub]`（扫描逻辑抽为 `commands/scan_skills.rs`，控制台 `/api/project/scan-skills` 共用同一实现）、`library --action delete --skill [--execute]`。
3. CLI 专项走查：真实 CLI 调用 + 磁盘核对，覆盖扫描边界、select/effective、sync 部署、undo 回滚与重复撤销拒绝、删除预览/执行/归档、CLI 与 Web 同状态一致性。

## 必须验收

- [x] CLI sync 部署后持久化撤销清单；undo 真实回滚磁盘；重复撤销被拒。
- [x] scan-skills 与控制台同一实现（宿主目录/指定根/托管分类/损坏条目独立报错）。
- [x] library delete 预览→执行→归档可恢复；非 ASCII 源目录导入需 ASCII 存储名（与 Web 一致）。
- [x] CLI 与 Web effective 同状态一致（pending/资源集合/宿主状态）。
- [x] 全量 cargo test 通过；控制台 undo 改用共用核心后无回归。
