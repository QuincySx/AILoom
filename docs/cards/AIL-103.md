## 按顺序实施

1. 宿主页显示支持宿主、检测状态、项目是否选用、实际能力；检测不到与未选用分开。
2. 保存项目宿主选择，不修改用户级宿主设置；关闭宿主时确认影响及待清理入口。
3. 按能力显示 Skill/MCP/Agent/指令支持情况，不支持不可假启用；需要新会话明确提示。
4. 明确本工具不部署不等于宿主全局能力已禁用；外部全局能力单独说明而非计作本项目引用。

## 必须走通的真实验收

- [ ] 分别只选 Claude、只选 Codex、均选、均不选，预览产物与能力矩阵一致。
- [x] 全局已有 Skill 而项目停用：UI 不得声称宿主已绝对禁用。
- [ ] 取消不写入；失败可恢复；重复提交不产生重复配置。
- [ ] 保存后刷新与服务重启持久化一致；其他项目和全局源无意外改变。
