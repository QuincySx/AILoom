## 目标与交付

支持业务仓库内部保存团队资源，同时机器数据外置，隔离资源贡献和统计历史。

## 文件职责

src/source/self_repo.rs、src/migration.rs、tests/self_repo.rs。已有等价模块应复用，共享接口不另起一套。

## 输入与输出

输入：现有独立源绑定或新同仓声明；输出：同仓资源视图、可审迁移计划和恢复记录。

## 实施步骤

1. 定义资源子树与业务树边界
2. 不重用会reset整个源目录的缓存流程
3. 贡献使用隔离worktree
4. 统计放独立报告分支
5. 迁移copy→校验→切换→保留备份
6. 绑定变更显式
7. 新旧锁与索引重建可追溯。

## 验收标准与必测场景

- [x] 业务dirty文件/当前branch全程不变
- [x] 同仓pull不清理代码
- [x] linked worktree资源仍写当前checkout
- [x] 迁移中断可恢复
- [ ] 跨文件系统不假定rename原子
- [x] 统计push不推进业务默认分支。

## 明确不做

- 不自动将用户已有仓库改成同仓模式
- 不在用户当前checkout git reset
- 不迁移凭据到可提交目录。
