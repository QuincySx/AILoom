- [ ] 本地启动可打开浏览器、端口占用可恢复、多实例不串会话；关闭/重启有准确状态，不无限挂起。

- [ ] 新增 API 有 schema、错误类型、配置 revision/ETag、幂等请求标识；过期保存保留草稿并返回冲突，不覆盖外部修改。
- [ ] 源 Markdown/名称作为不可信内容安全渲染，错误/日志不返回秘密；跨仓作用域需服务端重新验证。
- [ ] 浏览器目录选择通过用户指定根和受限浏览 API，不能将上传目录当成本机任意绝对路径；慢任务交给 050，不阻塞请求线程。
- [ ] 对照本地控制台规格的共同不变式，提供“验收项→真实入口→操作/命令→结果→证据”映射；未覆盖必需项保持开放。
