## 目标与交付

支持多个公共源、标签订阅、显式排除和来源锁文件；设计重复身份及跨源冲突处理。

## 验收标准

- [ ] 标签不替代项目身份
- [ ] 无循环订阅
- [ ] 冲突不依赖遍历顺序
- [ ] 锁定版本可复现
- [ ] 更新可预览和回退。

- 本卡限定以上交付；新增范围先更新卡片及依赖。

## 输入与输出

输入：sources列表、tags、exclude、各源revision；输出：完整锁文件和冲突可解释的资源集合。

## 实施步骤

1. 稳定source ID。
2. 限制订阅深度并检测循环。
3. 每源单独锁定。
4. 订阅不改变project/role语义。
5. exclude可覆盖选择但不产生隐式远端删除。
6. 同目标冲突要求显式重命名/排除。
7. 全量更新先计划再应用。

## 必测场景

- [ ] A订阅B/B订阅A拒绝。
- [ ] 源不可用保留已锁版本。
- [ ] 同名跨源报冲突。
- [ ] tags过滤不放大经验范围。
- [ ] 清理只处理该source所有权。
- [ ] 锁文件跨机器可复现。

## 明确不做

- 不采用源遍历顺序当优先级。
- 不让公共源自动改写团队管理员的项目定义。
