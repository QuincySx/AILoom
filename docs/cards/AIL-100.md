## 按顺序实施

1. 项目列表 → 打开项目，头部固定展示项目名、目录、Git/文件夹类型；切换工作树后全部面板绑定新目标。
2. 在配置头部提供清晰的项目默认/仅当前工作树范围选择；无 Git 项目不出现无意义工作树选项。子项目高级范围有入口和说明。
3. 显示本层选择、继承来源、有效配置、磁盘部署状态，禁止仅用一个“启用”混称。
4. 检查异步加载、保存时切换项目/工作树、返回前进与刷新；旧响应不能覆盖新目标，旧计划失效。
