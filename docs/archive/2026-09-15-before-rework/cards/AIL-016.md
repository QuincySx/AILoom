## 目标与交付

对经验、规则、Skills、Docs 建本地关键词索引；中文分词策略；recall 输出来源、得分和原文位置；可重建。

## 验收标准

- [x] A 只召回 A+共享，不召回 B
- [x] 零项目只召回允许公共集合
- [x] 项目切换与文档删除清理索引
- [x] 缺失索引能恢复
- [x] 索引过滤是相关性隔离，不冒充访问控制。

## 输入与输出

输入：锁定资源快照+允许namespace+query；输出：排序结果{id,title,score,source,scope,excerpt}与索引版本。

## 实施步骤

1. 索引身份绑定source revision+active项目集合+schema。
2. 索引前过滤namespace。
3. 分词/权重明确可测试。
4. 分离候选相关性和可见集合。
5. 写新索引后原子替换。
6. 检测缺失/旧版本重建。
7. 返回原文引用与无匹配状态。

## 必测场景

- [x] A/B含相同关键词仍无串项目结果。
- [x] 索引从A切B不会复用A缓存。
- [x] 删除文档无残留。
- [x] 中文查询有命中。
- [x] 零匹配不返回随机高分。
- [x] 共享root只索引显式共享。
- [x] 索引损坏可重建。

## 明确不做

- 不引入向量数据库作为首版必需依赖。
- 不把检索过滤称为权限隔离。
- 不让LLM过滤无权应见文档。
