## 目标与交付

init 绑定团队源、工作区、项目数组和角色；status 展示有效来源及待同步状态；可提交声明与本机数据分离。

## 验收标准

- [x] 重复 init 幂等
- [x] 非法项目/角色明确报错

- [x] 仅一个逻辑项目时也不默认授权式激活
- [x] 状态不含机器秘密。

## 输入与输出

输入：团队源、--project可重复、--role、cwd；输出：可提交声明+不含秘密的本机binding+初始source lock。

## 实施步骤

1. 加载并校验团队manifest。
2. 解析当前workspace。
3. 展示有效选择。
4. 原子保存声明和binding。
5. 重复绑定只改显式参数。
6. status显示声明/锁/实际部署是否一致。
7. 定义跨机器clone后的恢复步骤。

## 必测场景

- [x] A目录init A、B目录init B，缓存可共享但binding不同。
- [x] 重复init无冗余变更。
- [x] manifest只有A但用户不选时仍为空。
- [x] 未知项目返回可读错误。
- [x] 仓库移动后重新绑定不覆盖旧工作区。
